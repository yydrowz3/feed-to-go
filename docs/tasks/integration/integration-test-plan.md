## 验证与验收标准

- FFprobe 检查全部视频参数，FFmpeg 完整解码无错误；逐张检查封面与视频对应，核对文件大小、MD5、分片数量和末片长度。
- 浏览器确认视频时间推进、拖动进度和测试音轨正常；媒体请求直达后端，Range 请求正常，封面可读取。
- 续传确认跳过已接收分片，最终上传内容与本地文件一致，每个素材仅发布一次。
- 缺陷修复后运行相关测试；前端有改动时运行 `pnpm test`、`pnpm build`、`pnpm lint`，后端运行受影响包的测试。
- 报告逐项记录通过、失败或受阻，以及复现步骤和证据；仅对实际验证成功的项目更新现有验收记录。
